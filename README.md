# Project Portal (Role-Based Web Application)

## 📌 About Project
This is a full stack role-based web application built using:
- React.js (Frontend)
- Node.js + Express.js (Backend)
- MongoDB (Database)
- JWT Authentication

---

## 👥 User Roles

### Admin
- Manage users
- View statistics
- Edit/Delete users

### Client
- View assigned projects

### User
- View profile only

---

## ⚙️ Features
- Login / Register system
- JWT authentication
- Role-based routing
- Protected routes
- Admin dashboard
- Client dashboard
- User dashboard
- Logout functionality
